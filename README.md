# NOX

NOX — настольное приложение для просмотра и обработки одномерных Bruker ЯМР-спектров.

Возможности: фазирование, коррекция базовой линии, ручное интегрирование, сравнение нескольких спектров, визуальные формулы и сохранение проектов.

## Запуск

```powershell
python -m pip install -r requirements.txt
python main.py
```

Для загрузки выберите папку Bruker с обработанным спектром (`pdata/1/1r`).

## Основные файлы

- `main.py` — интерфейс и сценарии обработки.
- `base_line.py` — чтение Bruker-данных, фазирование и алгоритмы коррекции базовой линии.
- `nmr_dialogs.py` — модальные окна фазирования, коррекции линии, сравнения и точного X-сдвига.
- `nmr_io.py` — нативный Windows-диалог выбора нескольких папок Bruker.
- `project_store.py` — проверяемое отдельно чтение/запись проектов и упаковка обработанного сигнала.
- `alignment.py` — автоматическое совмещение спектров по X через корреляцию формы пиков.

Сырые спектры и локальные файлы проектов намеренно не входят в репозиторий.
